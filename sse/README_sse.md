# sse_det.py — 결정론적 루프 SSE (S = 1/2 Heisenberg 반강자성체, 이분 그래프)

## 무엇이 바뀌었나 (sse_h.py 대비)

- **루프 갱신.** 매 sweep마다 연산자 열의 모든 루프를 한 번씩 만들고 각 루프를 독립적으로 뒤집는다(Sandvik 2010의 결정론적 루프). 등방 Heisenberg에서 루프는 항상 닫히므로 길이 상한이 없고, 버려지는 루프도 없다. sweep 비용은 연산자 수에 비례한다.
- **평형화.** β를 2 이하에서 시작해 두 배씩 키운다(연산자 열 복제). 각 단계마다 `--neq` sweep을 쓴다.
- **고정 S^z 표본추출(`--fixM`).** S^z_tot을 바꾸지 않는 루프만 뒤집어 한 섹터만 표본추출한다. 섹터별 바닥 에너지 E₀(M)을 얻고, 자기장 결과는 E(h) = min_M [E₀(M) − hM]으로 만든다. 자기장 연구에는 이 방식을 권한다.
- **자기장 직접 모드(`--h`).** Zeeman 항은 H_J와 교환하므로 루프 단위 heat-bath로 정확히 넣었다. 다만 낮은 온도에서 S^z 섹터 사이 이동이 느려 갇힐 수 있다(4×4, β = 50, h = 1에서 10개 시드 중 3개가 틀린 섹터). 쓰려면 여러 시드로 ⟨M⟩을 확인할 것.

## 검증 (`python validate.py`, 약 1–2분)

| 시험 | 기준 | 결과 |
| --- | --- | --- |
| dice_L1_N12, β = 60 | ED −7.869160 | −1.2σ |
| z5crystal_L1_N15, β = 60 | ED −10.088068 | −0.3σ |
| 4×4 정사각, fixM = 0, 1, 2, β = 50 | ED 섹터 에너지 | −1.5σ, +0.2σ, −0.6σ |

## 사용법

```
python sse_det.py ../qmc_inputs/facet_1band_N164.json --beta 300 --neq 2000 --nbins 100 --spb 2000 --seed 1
python sse_det.py ../qmc_inputs/facet_1band_N164.json --beta 300 --fixM 1       # 섹터 S^z = 1
```

출력 JSON: `E`, `E_err`(빈 사이 표준오차), `E_J`(교환 에너지), `M`, `n_ops`, `L_cut`, `sweeps_per_s`, `bins_E`(빈 평균 목록, 재빈닝으로 자기상관 확인용). 오차는 빈 크기를 키워도 변하지 않아야 한다.

## 속도 (이 환경, 단일 코어)

N = 164, β = 300: ⟨n⟩ ≈ 5.8×10⁴, 약 118 sweep/s. 빈 1000 sweep의 에너지 표준편차가 약 0.05 J이므로, 총에너지 오차 0.003 J에는 약 2.5×10⁵ sweep, 즉 약 35분이 든다.
