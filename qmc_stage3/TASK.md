# 작업 지시: 8겹 타일링 QMC 3단계 (Hartree 예측의 블라인드 검증)

2단계에서 QMC/LSWT 비율이 LSWT 상관함수에서 계산한 Hartree 비율로 예측된다는 관계를 얻었다.

r_QMC ≈ 1.114 + 1.152 (r_H − 1)   (측정 8개 상, 상관 0.989, rms 0.018)

이번에는 측정하지 않았던 상 4개로 이 예측을 블라인드 검증한다. 예측값은 각 입력 JSON의 `r_QMC_predicted`에 미리 적혀 있다.

## 0. 준비

```
pip install numpy scipy numba
cd sse && python validate.py      # ALL PASS 확인 (필요한 ED 그래프는 qmc_inputs/에 포함)
cd ..
```

## 1. 실행

```
python run_queue.py -j <코어 수>
```

| 상 | 크기 (N) | 역할 | 예측 r_QMC |
| --- | --- | --- | --- |
| (4,0,6,2), τ = 0.40 | 176, 704 | m = 0.058–0.103 계단 | 1.159 |
| (4,2,2,2), τ = 0.50 (4가족) | 160, 640 | m = 0.154 계단 | 1.220 |
| (5,0,3,3), τ = 0.42 | 156, 624 | m = 0.126 근처 | 1.216 |
| (6,0,6,2), τ = 0.33 | 240, 540 | m = 0.046 계단 | 1.131 |

단일 코어 약 40–50분, `-j 4`면 약 15분.

## 2. 분석

```
python analyze.py > results.md
cd lp && python analyze_hartree.py >> ../results.md && cd ..
```

첫 줄은 측정 비율과 예측 비율을 비교한다. 두 번째 줄은 측정 비율로 해당 상을 바꿔 128개 상의 자화 계단을 다시 푼다.

## 3. 보고

`results.md` 전체와 판정:
- 각 상의 큰 크기에서 |측정 − 예측| ≤ 0.04이면 통과(맞춤 rms의 약 2배)
- 작은 크기와 큰 크기의 비율이 같은지(크기 수렴)
- 다시 푼 계단의 시작, m = 0.114 고원, m = 0.190 고원, 포화 문턱

결과는 `eightfold-tiling-qmc` 저장소의 `qmc_stage3/`에 둔다. 모든 스크립트는 Python 3.10 이상에서 동작한다.
