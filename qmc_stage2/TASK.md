# 작업 지시: 8겹 타일링 QMC 2단계 (새 상들의 QMC 보정)

1단계(`qmc_code_package`)와 같은 SSE 코드와 같은 방식이다. 목적은 v5 자화 계단에 새로 들어온 상들의 QMC/LSWT 비율을 재서, 중간 고원들의 순서가 QMC에서도 유지되는지 판정하는 것이다.

## 0. 준비

```
pip install numpy scipy numba
cd sse && python validate.py      # 마지막 줄이 ALL PASS여야 한다
cd ..
```

## 1. 실행

```
python run_queue.py -j <코어 수>
```

끝난 작업은 건너뛴다. 단일 코어 약 1.5시간, `-j 4`로 약 25–30분.

| 계 | N | 역할 | 확인 |
| --- | --- | --- | --- |
| m1partner (σ = 1/2, τ = 1/3), L = 4, 6 | 432, 972 | m₁ 고원 짝 | 크기 수렴 |
| hub (σ = 1/2, τ = 1/9), L = 4 | 432 | 고립 z=6 허브(자화당 가장 쌈) | β = 300 대 600 |
| kappa1 (σ = 1/4, τ = 1/2), L = 4, 6 | 320, 720 | κ_B = 1 상 | 크기 수렴 |
| kappa89 (σ = 3/8, τ = 1/2), L = 2, 4 | 176, 704 | m = 0.190 고원 짝 | 크기 수렴 |
| fourfam (4,1,4,1), τ = 1/2, L = 2, 4 | 136, 544 | 4가족 부분 분극 상 | 크기 수렴 |
| runs3_d5 (꺾임 간격 3 띠), L = 15, 30 | 315, 1260 | 자화 시작 상 | 크기 수렴 |

## 2. 분석

```
python analyze.py > results.md
```

`analyze.py`는 마름모당 ε의 QMC/LSWT 비율표를 만들고, 그 비율로 128개 상의 에너지를 보정해 QMC 보정 자화 계단(선형계획)을 출력한다. 측정하지 않은 상에는 측정된 비율의 평균을 쓴다. 결정 두 개는 1단계 비율(z=5 결정 1.287, 다이스 1.250)을 쓴다.

## 3. 보고

`results.md` 전체와 다음 판정:

- 각 상의 비율이 크기(L)에 따라 수렴하는지, hub의 β = 300과 600이 같은지.
- 상들 사이 비율의 차이. 모두 1.25–1.3 근처면 LSWT 계단의 순서가 유지되고, 차이가 크면 중간 고원의 순서가 바뀐다.
- QMC 보정 계단표에서 자화 시작, m₁ 고원, 포화 문턱의 값.

결과는 8겹 연구용 저장소나 폴더에 둔다(도미노 저장소의 `claude/youthful-wright-fiys4k` 브랜치에는 두지 않는다).
